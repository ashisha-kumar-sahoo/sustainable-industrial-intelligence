# Operations Intelligence ML Framework

## Overview

The Operations Intelligence framework provides dataset-independent
machine learning and analytics modules for industrial operations.

The framework contains four intelligence domains:

1. Environment Intelligence
2. Traffic Intelligence
3. Equipment Intelligence
4. Safety Intelligence

## Architecture

```text
Operations Intelligence
│
├── Environment Intelligence

│   ├── Preprocessing
│   ├── Anomaly Detection

│   └── Evaluation

├── Traffic Intelligence

│   ├── Preprocessing

│   ├── Parking Analysis
